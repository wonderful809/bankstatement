Setup & Preview Instructions

⚠️ Connection Refused Error?

This means the Flask server is not running yet. You need to start it first!

📋 Quick Start Steps

  1. Open a Terminal/Command Prompt
    On your computer, open Terminal (Mac/Linux) or Command Prompt (Windows)
  2. Navigate to the workspace directory
    cd /workspace
  3. Start the Flask server
    python3 RUN_SERVER.py
    Alternative: python3 app_bankstatement_saas.py
  4. Wait for the server to start
    You should see: "Running on http://0.0.0.0:5000"
  5. Open your browser and visit
    http://localhost:5000

🐛 Troubleshooting

"Port 5000 already in use"

Run this to kill existing process:

# Linux/Mac
lsof -ti:5000 | xargs kill -9

# Or use a different port
export FLASK_PORT=5001
python3 app_bankstatement_saas.py

"Module not found"

Install dependencies:

pip install -r requirements.txt
