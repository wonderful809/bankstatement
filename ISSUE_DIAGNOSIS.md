## 🚨 ROOT CAUSE IDENTIFIED

```
❌ ERROR: Tesseract not found. 
Install Tesseract or set TESSERACT_CMD env var.
```

### What This Means:

1. **The uploaded PDF is a scanned document** (image-based, not text-based)
2. **OCR processing is required** to extract text from scanned images
3. **Tesseract OCR is not installed** on the system
4. **Without Tesseract, scanned PDFs cannot be processed**

### Why This Happened:

The application has two processing paths:

```
┌─────────────┐
│  PDF Input  │
└──────┬──────┘
       │
       ├─ Text-based PDF? ──YES──> Use pdfplumber (works) ✅
       │
       └─ Scanned PDF? ──YES──> Use Tesseract OCR (MISSING) ❌
```

The test PDF was scanned, which triggered the OCR path, but Tesseract is not installed.

---

## ✅ Solution

### Option 1: Install Tesseract (Recommended)

**For Production Use:** Install Tesseract OCR

1. **Download Installer:**
   - Windows: [https://github.com/UB-Mannheim/tesseract/wiki](https://github.com/UB-Mannheim/tesseract/wiki)
   - Download `tesseract-ocr-w64-setup-5.3.x.exe`

2. **Run Installer:**
   - Double-click and follow wizard
   - Default path: `C:\Program Files\Tesseract-OCR`

3. **Verify Installation:**
   ```powershell
   tesseract --version
   ```

4. **Restart Application:**
   ```powershell
   # Stop Flask (Ctrl+C)
   python app.py
   ```

5. **Test Again:**
   - Upload the same PDF
   - Should now extract transactions successfully ✅

**Full Guide:** See [TESSERACT_INSTALLATION.md](./TESSERACT_INSTALLATION.md)
